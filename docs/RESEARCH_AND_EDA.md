# SmartMaintain-XAI: Research, EDA & Domain Feature Documentation

This directory contains technical research, Exploratory Data Analysis (EDA) scripts, and domain physics formulation notes for **SmartMaintain-XAI**.

---

## 1. Dataset Architecture & Baseline Statistics

The system uses a combined evaluation dataset of **22,500 industrial machine records**:
1. **Authentic UCI AI4I 2020 Dataset**: 10,000 baseline industrial machine records.
2. **25-Machine Multi-Pattern Synthetic Dataset**: 12,500 records generated across 25 equipment models ($25 \times 500$ samples: $80\%$ Normal / $20\%$ Failure).

### Target Class Distribution
- **Normal Operation (Class 0)**: 19,661 records (87.4%)
- **Failure Scenarios (Class 1)**: 2,839 records (12.6%)

## 2. Feature Engineering & Stress Formulations

Four domain-specific features and four machine-relative stress ratios are computed during preprocessing:

### Physics & Operating Indicators
1. **Heat Dissipation Delta ($\Delta T$)**:
   $$\text{temp\_difference\_k} = T_{\text{process}} - T_{\text{air}}$$
   - *Domain Meaning*: Measures internal process heat buildup relative to ambient air. Elevated $\Delta T$ indicates cooling system degradation.

2. **Mechanical Power Output ($P_{\text{kW}}$)**:
   $$P_{\text{kW}} = \frac{2 \cdot \pi \cdot N_{\text{RPM}} \cdot T_{\text{Nm}}}{60,000}$$
   - *Domain Meaning*: Mechanical power generated by shaft rotation $N$ and torque $T$.

3. **Tool Wear Rate ($W_{\text{rate}}$)**:
   $$W_{\text{rate}} = \frac{\text{tool\_wear\_min}}{N_{\text{RPM}} + 10^{-5}}$$
   - *Domain Meaning*: Tool wear rate relative to shaft rotation speed.

4. **Temperature-to-Torque Ratio ($R_{\text{TT}}$)**:
   $$R_{\text{TT}} = \frac{T_{\text{process}}}{T_{\text{Nm}} + 10^{-5}}$$

### Machine-Relative Stress Ratios
To handle non-stationary normal ranges across 25 distinct machine types (e.g., Gas Turbine 3000–6000 RPM vs Extruder 400–1500 RPM), sensor values are normalized against each equipment model's rated design bounds:

$$\text{rpm\_stress} = \frac{N_{\text{RPM}}}{N_{\text{max\_rated}}}$$
$$\text{torque\_stress} = \frac{T_{\text{Nm}}}{T_{\text{max\_rated}}}$$
$$\text{wear\_stress} = \frac{\text{tool\_wear\_min}}{W_{\text{max\_rated}}}$$
$$\text{temp\_stress} = \frac{T_{\text{process}}}{T_{\text{max\_rated}}}$$
